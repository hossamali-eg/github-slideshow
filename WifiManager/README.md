# WiFi Manager - تطبيق إدارة الشبكة

تطبيق Android متكامل للتحكم الكامل في الراوتر والشبكة.

## المميزات

### لوحة التحكم الرئيسية
- عرض حالة الإنترنت (مفعّل / موقف)
- سرعة التنزيل والرفع في الوقت الفعلي
- قياس الـ Ping
- إجراءات سريعة

### إدارة الأجهزة
- عرض جميع الأجهزة المتصلة مع أيقونات مناسبة
- معرفة IP وMAC لكل جهاز
- سرعة كل جهاز بشكل منفصل
- **حجب أي جهاز** عن الإنترنت
- **تحديد سرعة** التنزيل والرفع لكل جهاز
- تسمية الأجهزة بأسماء مخصصة
- فلترة: الكل / متصل / غير متصل / محجوب

### التحكم في الإنترنت
- تشغيل/إيقاف الإنترنت بضغطة واحدة
- **إيقاف مؤقت** لفترة زمنية محددة (15 دق / 30 دق / ساعة...)
- إيقاف الإنترنت عن جميع الأجهزة دفعة واحدة

### الجدولة الزمنية
- إضافة قواعد جدولة (إيقاف/تشغيل الإنترنت)
- تحديد الأيام والأوقات
- **جدولة لكل جهاز على حدة**
- تفعيل/تعطيل القواعد بسهولة

### الوصول عن بُعد
- التحكم بالراوتر بدون الاتصال بنفس الواي فاي
- عبر Firebase Cloud Messaging
- أو عبر Remote Management للراوتر

## أنواع الراوترات المدعومة
- **TP-Link** (API مباشر)
- D-Link
- Huawei
- ASUS
- Netgear
- MikroTik
- OpenWRT
- Generic (أي راوتر)

## التثبيت والإعداد

### متطلبات
- Android 8.0 (API 26) أو أحدث
- صلاحيات الشبكة
- الاتصال بنفس شبكة الراوتر (للتحكم المباشر)

### خطوات الاستخدام
1. افتح التطبيق وادخل IP الراوتر (عادة 192.168.1.1)
2. أدخل اسم المستخدم وكلمة المرور للراوتر
3. اختر نوع الراوتر من القائمة
4. اضغط "اتصال"

### الوصول عن بُعد
لاستخدام التطبيق من خارج الشبكة:
1. فعّل "Remote Management" في إعدادات الراوتر
2. اضبط Dynamic DNS
3. أو استخدم Firebase للتحكم عبر FCM

## البنية التقنية

```
Clean Architecture + MVVM
├── data/
│   ├── api/          (HTTP Router API)
│   ├── db/           (Room Database)
│   ├── models/       (Data Models)
│   └── repository/   (Single Source of Truth)
├── ui/
│   ├── login/        (شاشة تسجيل الدخول)
│   ├── dashboard/    (لوحة التحكم)
│   ├── devices/      (إدارة الأجهزة)
│   ├── scheduler/    (الجدولة)
│   └── settings/     (الإعدادات)
└── service/          (Background monitoring)
```
